# Student Record Management System

## Project Overview

The Student Record Management System is a menu-driven console application developed using Python. This project allows users to perform CRUD operations on student records efficiently through the terminal.

---

## Features

- Add Student Record
- View All Student Records
- Search Student by Roll Number
- Update Student Marks
- Delete Student Record
- Input Validation
- Error Handling using try-except
- Percentage Calculation
- Formatted Table Display

---

## Technologies Used

- Python 3.x
- Standard Python Libraries Only

---

## How to Run the Project

1. Download or clone the repository.
2. Open terminal in project folder.
3. Run the following command:

```bash
python main.py
